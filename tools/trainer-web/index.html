Meter model trainer

backend …v0.1 proof

Trains the digit model for AI-on-the-edge in this browser and exports a .tflite file the device can load. Nothing leaves this computer.

1Load labelled crops

A dataset zip with labels.csv (path, src, pos, label, split, ts) and the crop images. Labels are a digit, or two digits for a wheel between them (7/8).

Drop the dataset zip here, or click to choose it

2Train

Training continues while this tab is in the background; progress shows in the tab title. Keep the tab open and don't let the computer sleep: sleep pauses it, and closing the tab loses the run.

train lossvalidation loss

3Check on held-back crops

Crops from the test split (the newest days) were never used for training. A transition crop counts as right when the model picks either of its two digits.

4Export for the device

Upload the file to /config/ on the device and select it as the digit model in the configuration. Keep the old model file until the new one has run for a day.
