Train a better digit model overview

This page collects the digit images the device saves, labels them, trains a new digit model in this browser and installs it on the device. Images stay in this browser; they only go to an AI server if you set one up in step 3. Go through the steps one by one, or let the automatic run do steps 2 to 5.

Automatic run

Work continues while this tab is in the background; progress shows in the tab title. Keep the tab open and the computer awake.

1 · Device setup checking

    2 · Collect images –

    Copies the digit images the device saved into this browser. Checking first lists the device's folders and shows how much there is to download. Images are grouped by wheel and by what the device read (a digit, a position between two digits, or a rejected reading); of each group only "images per reading" are kept, spread over the days. A wheel at rest shows the same digit for days, so most of its images are skipped. The device sends about three images a second.

    Delete all images, labels and models stored in this browser?

    3 · Labels –

    Each image gets the label its sources agree on: the device's own reading, a wheel that stayed the same for several readings, an AI model's answer, and your corrections (yours always win). Only images with two agreeing sources, or your label, are used for training.

    AI labelling server (Ollama or OpenAI-compatible)

    Ollama has to allow this page: start it with OLLAMA_ORIGINS= (and OLLAMA_HOST=0.0.0.0 when it runs on another computer). With an online service, the images you label are sent to it, and the key is stored in this browser.

    The images are spread over all wheels and readings: readings with the fewest usable labels go first, then one image per reading in turn, from different days. Disagreements are asked about before unconfirmed images.

    Review

    Click an image, then: 0–9 digit · T then a digit for between two digits (T 6 = 6/7) · X unusable · Backspace remove your label · ← → move · Enter accept the shown label.

    5 · Install on the device –

    Installing uploads the model to /config/, saves a copy of the configuration next to it, switches the digit model right after a reading round and restarts the device, then waits for its first reading. The previous model file stays on the card.
